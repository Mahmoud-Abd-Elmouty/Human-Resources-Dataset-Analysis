> What makes employees happy, and what makes them leave? An HR dataset explored end to end in Power BI.

## Overview

HR teams make constant decisions about hiring, pay, and retention, but those decisions are only as good as the numbers behind them. This project takes an HR dataset, cleans it, and turns it into an interactive Power BI dashboard that answers the questions HR decision makers actually ask.

It is built as a team project in the Digital Egypt Pioneers Initiative (DEPI) data analysis track.

## Questions We Want to Answer

| Question | Decision it supports |
| -------- | -------------------- |
| How does age relate to employee satisfaction? | Targeting engagement programs |
| Which departments and roles lose the most people? | Where to focus retention efforts |
| Do pay, overtime, or tenure affect who stays? | Compensation and workload planning |
| What does the workforce look like by age, gender, and department? | Hiring and diversity planning |

> The final list will be confirmed once we review the dataset.

## How We're Doing It

- [ ] **1. Clean and prepare the data** in Power Query. Output: a cleaned dataset and a written record of every cleaning step.
- [ ] **2. Define the analysis questions.** Output: a documented set of questions the data can answer.
- [ ] **3. Build the dashboard** with a data model and DAX measures. Output: a Power BI file (`.pbix`).
- [ ] **4. Report and present** the findings and recommendations. Output: a final report and slides.
